# Jeu d'aventure 2D

Jeu vidéo d'aventure en 2D, vue de côté.

## Histoire — début
Le héros se réveille dans son lit, sort de sa maisonnette et se dirige vers le village.

## Héros
- Garçon
- Cheveux bruns
- T-shirt noir
- Pantalon brun

## Prototype
Cette première version contient une scène de départ, un personnage contrôlable et un village simple.

## Commandes
- Flèches gauche/droite ou A/D : se déplacer
- Espace : sauter
- R : recommencer
